Rules that keep the flow correct

The main risk is date arithmetic, not infrastructure.

Clamp the day to the target month

Months have different lengths. Use the final day of the target month when the original day does not exist.

2026-10-31 + 1 month = 2026-11-30
2024-01-31 + 1 month = 2024-02-29Math.min(day, daysInMonth(…))src/domain/dates.ts:52

Due today is not overdue

Compare validated, zero-padded date strings. Use one shared local date for the action and status checks.

next_due === today → due-today

Only last_completed changes. Due dates, statuses, and counts derive from the current item array. A same-day repeat changes nothing.

18  const result = Papa.parse<CsvRecord>(text.replace(/^\uFEFF/, ''), {
19    header: true,
20    skipEmptyLines: 'greedy',
21    transformHeader: (header) => header.trim(),

25/** True only for a zero-padded `YYYY-MM-DD` value that names a real calendar day. */
26export function isCalendarDate(value: string): value is CalendarDate {
27  const match = ISO_DATE.exec(value)
28  if (!match) return false
29  const year = Number(match[1])
30  const month = Number(match[2])
31  const day = Number(match[3])
32  return month >= 1 && month <= 12 && day >= 1 && day <= daysInMonth(year, month)
33}

43/**
44 * Add whole calendar months. If the source day does not exist in the target
45 * month, use the target month's last day (2026-01-31 + 1 = 2026-02-28).
46 */
47export function addMonthsClamped(date: CalendarDate, months: number): CalendarDate {
48  const [year, month, day] = parts(date)
49  const monthIndex = year * 12 + (month - 1) + months
50  const targetYear = Math.floor(monthIndex / 12)
51  const targetMonth = (monthIndex % 12) + 1
52  const targetDay = Math.min(day, daysInMonth(targetYear, targetMonth))
53  return `${pad(targetYear, 4)}-${pad(targetMonth)}-${pad(targetDay)}`
54}

20  today: CalendarDate,
21): MaintenanceItem[] {
22  let changed = false
23  const next = items.map((item) => {
24    if (item.item_id !== itemId || item.last_completed === today) return item
25    changed = true

31/** Derive the next due date, status, and completed-today flag for one item. */
32export function toMaintenanceRow(item: MaintenanceItem, today: CalendarDate): MaintenanceRow {
33  const next_due = addMonthsClamped(item.last_completed, item.frequency_months)
34  return {
35    ...item,
36    next_due,
37    status: getStatus(next_due, today),
38    completed_today: item.last_completed === today,

46/**

67/**

69 * `next_due <= today`, so it includes due-today rows.

71export function matchesView(row: MaintenanceRow, view: TaskView): boolean {
72  if (view === 'due') return row.status !== 'upcoming'
73  if (view === 'completed-today') return row.completed_today

77/** Count the rows in each view. Pass the rows of the selected properties. */

86/**
87 * Keep only the rows in a view, in source order. Recount overdue rows for each
88 * group and remove groups with no rows. The All tasks view returns the input.

90export function filterGroupsByView(groups: readonly PropertyGroup[], view: TaskView): PropertyGroup[] {
91  if (view === 'all') return groups as PropertyGroup[]
